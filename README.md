# Odoo 18 MCP Connector Workspace (`odoo-mcp`)

Enterprise Model Context Protocol (MCP) server workspace for Odoo 18.

## Structure
- `custom_addons/mcp_connector/`: Main Odoo 18 MCP Connector module
- `logs/`: Application execution logs
- `backups/`: Database backups
- `scripts/`: Helper launch and update scripts
- `docs/`: System documentation
- `tests/`: Automated unit test suite
